# AlphaAI · The 6-Layer Cake Framework for AI Investment Intelligence

An institutional market intelligence and investment platform tracking the AI economy across all 6 structural layers: from **Energy & Grid Infrastructure** up to **Vertical Applications & Agentic AI**.

## The 6 Layers
1. **Layer 1: Energy & Grid Infrastructure** (CEG, VST, TLN, Vertiv, SMRs, Liquid Cooling)
2. **Layer 2: Silicon & Semiconductor Fabrication** (NVDA, TSMC, ASML, Broadcom, HBM, CoWoS)
3. **Layer 3: Cloud Infrastructure & Networking** (Azure, AWS, GCP, OCI, CoreWeave, Arista 800G)
4. **Layer 4: Foundation Models & Frontier Labs** (OpenAI, Anthropic, Meta Llama, xAI, RLVR)
5. **Layer 5: Developer Tooling, Data & MLOps** (Databricks, Scale AI, Pinecone, vLLM)
6. **Layer 6: Vertical Applications & Agentic AI** (Palantir, Cursor, Devin, ServiceNow, Harvey)

## Features
- **Layer-by-Layer Moat Matrix:** Deep margin profiles, risk factors, and value capture analysis.
- **Valuation Radar:** Public multiples (P/E, EV/Sales, CapEx %) and Private Unicorns funding rounds.
- **$300B+ CapEx Flow Simulator:** Tracking hyperscaler capital flows and value realization.
- **Supply Chain Bottleneck Monitor:** Real-time lead times (transformers 36mo, CoWoS, HBM).
- **Portfolio Allocator & Scenario Engine:** Custom 6-layer weighting and 5-year compounding simulations.

## Tech Stack
- **Backend:** Python 3.14 + FastAPI + `uv`
- **Frontend:** React 19 + TypeScript + Vite + Bun + Tailwind CSS v4 + Recharts
